# Java Local Life Commerce

一个统一的 Java 微服务项目，将本地生活社交与电商交易能力纳入同一套身份、网关、服务发现和消息体系。

> 当前阶段：源码迁移与统一构建骨架。迁移完成前，不将旧项目中的技术依赖描述为本项目已验证的端到端能力。

## 目标业务

- 电商：用户、商品、购物车、交易订单、余额支付。
- 本地生活：商户与分类、笔记与评论、关注关系和 Feed、优惠券。
- 集成链路：统一用户身份；本地生活优惠券进入统一订单/支付流程；支付状态通过消息更新交易状态。

## 模块

| 模块 | 职责 |
|---|---|
| `hm-gateway` | 统一入口、路由和认证上下文传递 |
| `user-service` | 统一用户身份与账户 |
| `item-service` | 电商商品 |
| `cart-service` | 购物车 |
| `trade-service` | 统一交易订单 |
| `pay-service` | 支付与支付结果事件 |
| `local-life-service` | 商户、内容社交、优惠券与本地生活订单入口 |
| `hm-api` / `hm-common` | 服务契约、共享基础能力 |

## 代码来源

- Spring Cloud 电商基础来自本地 `hmall_springCloud` 项目，保留其网关、用户、商品、购物车、交易、支付及公共模块代码。
- 本地生活业务来自 `hm-dianping` 项目，迁入 `local-life-service`。迁移时会统一身份、依赖、配置和订单边界；旧有实现中的未验证逻辑会在对应迁移阶段修复。
- `hm-service` 是旧工程中的重复单体版本，不作为新系统运行模块迁移。
